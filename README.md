# MIA Clara · Arquitectura

Guía de estudio interactiva de la arquitectura de **MIA Clara** (Certificación y Gestión): stack y decisiones de arquitectura,
frontend, backend y APIs, seguridad, datos, Docker, Kubernetes (k3s), Terraform, Ansible, CI/CD con GitHub Actions,
Cloudflare Tunnel, operación, evolución, laboratorios, explorador archivo por archivo y examen.

Sitio estático (HTML, CSS y JavaScript sin build) publicado con GitHub Pages.

- `index.html`: las lecciones.
- `assets/archivos.js`: catálogo de archivos, generado con `python3 herramientas/generar_archivos.py <ruta-core> <ruta-admin>`.
- `assets/preguntas.js`: examen de autoevaluación.

No contiene secretos, identificadores de cuenta, IP internas ni correos.
